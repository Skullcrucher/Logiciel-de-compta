☁️ Sauvegarde automatique sur Google Drive

Pas encore connecté. Suivez le tutoriel ci-dessous (10 minutes, une seule fois).

📘 Tutoriel : créer votre lien Google Drive (/exec) et votre code secret

Le principe : un petit programme (« script ») placé dans VOTRE compte Google enregistre la sauvegarde dans un fichier comptes-famille.json de votre Drive. Personne d'autre n'y a accès sans le lien ET le code secret.

  1. Sur un ordinateur, connecté à votre compte Google, ouvrez script.google.com puis cliquez sur « Nouveau projet ».
  2. Effacez tout le contenu affiché (function myFunction() {…}), puis collez à la place le code ci-dessous : 
    
            Donnez un nom au projet (en haut à gauche, ex. « Comptes famille ») et cliquez sur 💾 Enregistrer.
    3. 
          
  3. Choisissez un code secret : une longue phrase que vous seul connaissez (ex. violon-tomate-47-nuage-bleu). Dans le menu de gauche, cliquez sur ⚙️ Paramètres du projet, descendez jusqu'à « Propriétés du script » → « Ajouter une propriété » : Propriété = TOKEN, Valeur = votre code secret → Enregistrer.
    4. 
          
  4. En haut à droite : Déployer → Nouveau déploiement. Cliquez sur la roue ⚙️ à côté de « Sélectionner le type » → Application Web. Réglez Exécuter en tant que : Moi et Qui a accès : Tout le monde, puis Déployer.
    5. 
          
  5. Google demande d'autoriser l'accès : choisissez votre compte. S'il affiche « Google n'a pas validé cette application », cliquez sur Paramètres avancés → Accéder à … (non sécurisé) → Autoriser. C'est normal : c'est votre propre script, il n'accède qu'à votre Drive.
    6. 
          
  6. Copiez l'URL de l'application Web affichée : elle commence par https://script.google.com/macros/s/ et se termine par /exec. Collez-la dans le champ « Lien de votre script » ci-dessus, tapez votre code secret dans le champ d'à côté, puis cliquez sur Connecter.
    7. 
          
  7. Sur vos autres appareils (téléphone, tablette…), ouvrez l'application et collez le même lien et le même code secret : tout le monde partage alors les mêmes comptes.
    8. 
        

        
Copies de secours sur Drive : le script garde chaque jour une copie de vos données dans le dossier « Comptes famille - sauvegardes » de votre Drive (30 derniers jours). Pour revenir à l'une d'elles : téléchargez-la depuis Drive, puis Réglages → Importer une sauvegarde.

        
Vous modifiez le script plus tard (ou l'appli vous demande de le mettre à jour) ? Remplacez tout le code par celui ci-dessus et enregistrez, puis Déployer → Gérer les déploiements → ✎ → Version : « Nouvelle version » → Déployer. Le lien /exec reste le même. (Un « Nouveau déploiement » créerait un nouveau lien.)

        
« Code secret refusé » ? Le code tapé ici doit être exactement la valeur de la propriété TOKEN (attention aux espaces et majuscules).

      

      
    


    

      
📁 Sauvegarde automatique dans un dossier (OneDrive, Dropbox, iCloud…)

      
Choisissez un fichier dans un dossier synchronisé sur cet ordinateur — par exemple votre dossier OneDrive. L'application y réécrit la sauvegarde à chaque modification, et OneDrive l'envoie dans le cloud. Fonctionne sur ordinateur avec Chrome ou Edge.

      

        
        
        
        
      

      
Non configurée.

      

        📘 Comment ça marche avec OneDrive ?
        
    
          
  1. Installez l'application OneDrive sur votre ordinateur (déjà présente sur Windows 10/11) et connectez-vous : un dossier OneDrive apparaît dans l'explorateur de fichiers.
    2. 
          
  2. Cliquez sur « Choisir le fichier de sauvegarde… », ouvrez le dossier OneDrive (ou un sous-dossier, ex. OneDrive/Comptes) et validez le nom comptes-famille.json.
    3. 
          
  3. Le navigateur demande l'autorisation de modifier ce fichier : acceptez. Chaque modification y est ensuite enregistrée en quelques secondes.
    4. 
          
  4. Après avoir fermé le navigateur, il faut parfois cliquer sur « ▶ Réactiver » (le navigateur redemande l'autorisation par sécurité).
    5. 
          
  5. Pour retrouver vos données sur un autre ordinateur : choisissez le même fichier puis « Restaurer depuis ce fichier ». Sur téléphone, utilisez Importer une sauvegarde en ouvrant le fichier depuis l'application OneDrive.
    6. 
        

        
Contrairement à Google Drive, cette sauvegarde est à sens unique (cet ordinateur → OneDrive) : elle ne synchronise pas automatiquement plusieurs appareils entre eux. Une connexion directe à OneDrive demanderait d'enregistrer l'application auprès de Microsoft (compte développeur Azure) ; la synchronisation entre appareils reste donc assurée par Google Drive.
